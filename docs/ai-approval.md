# 智能审批

Ping Island 可以把响应式 Hook 审批交给用户配置的 OpenAI 兼容模型判断。此功能默认关闭，不改变 Hook 安装内容，也不处理 AskUserQuestion、通知型事件、Codex App Server 或 Native Runtime 审批。

## 配置

在“设置 → 智能审批”中填写 Base URL 和模型名。API Key 会保存在 macOS Keychain；不需要鉴权的本机服务可以留空。HTTPS 可连接任意地址，明文 HTTP 仅允许 `localhost`、`127.0.0.1` 和 `::1`。

可选模式：

- 关闭：所有审批继续由用户处理。
- 仅低风险自动：只有模型返回“允许 + 低风险”时自动允许一次；拒绝和中高风险结果保留给用户确认。
- 全自动：自动执行模型返回的允许或拒绝。

模型永远不能自动选择“本会话始终允许”。接口失败、超时或返回无效结构时，原审批保持打开并转回人工处理。

## 发送的数据

每次判断包含客户端、工作目录、工具名、审批说明、脱敏并截断的工具参数，以及最近 6 条用户/助手文本。Thinking、工具结果和问题表单不会发送；password、secret、token、authorization、api-key 等敏感字段会被替换为 `<redacted>`。

配置的模型服务可能保留请求数据，请按服务提供方的数据政策评估是否启用。自定义规则只会补充固定安全提示词，不能扩大模型的响应类型。

## 本地审计

审计记录在 Application Support 下保留 30 天，最多 1,000 条，可从设置页清空。记录包含模型、工具摘要、决定、风险、理由、耗时和执行结果，不保存 API Key、完整对话或完整工具参数。
