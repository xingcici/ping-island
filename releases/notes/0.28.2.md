## 改进
- 智能审批使用 `qwen3.7-flash` 及其版本后缀时，自动在请求 JSON 中发送 `"enable_thinking": false`，启用百炼非思考模式
- 其他 OpenAI 兼容模型不会收到该专用字段，保持现有接口兼容性

## 说明
- `enable_thinking` 是模型请求体字段，不是 HTTP Header
- 智能审批只处理可回写的单次 Hook 请求，不会自动授予整个会话权限
- 应用版本为 `0.28.2 (71)`；`xingcici/ping-island` fork 使用 `v0.28.2-x` Release 标识

## Improvements
- Sends `"enable_thinking": false` in the model request JSON for `qwen3.7-flash` and version-suffixed variants, enabling Bailian's non-thinking mode
- Keeps the provider-specific field out of requests to other OpenAI-compatible models

## Notes
- `enable_thinking` is a model request-body field, not an HTTP header
- Model-assisted approval only resolves responsive single-hook requests and never grants session-wide access
- The app version is `0.28.2 (71)`; the `xingcici/ping-island` fork uses the `v0.28.2-x` Release identifier
