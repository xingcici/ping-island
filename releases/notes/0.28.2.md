## 改进
- Codex rollout 采用游标和累积状态增量解析，文件追加时只处理新增 JSONL 数据
- 冷启动会在 JSON 解码前跳过不参与会话状态或历史展示的记录，显著降低大型会话的解析成本
- 会话快照与并发审批队列改为线性合并，避免长会话历史触发平方级 CPU 开销
- 文件刷新不再先请求完整 App Server turns，打开会话详情时优先复用本地缓存

## 修复
- 正确处理分段写入的最后一条 JSONL，避免并发追加时丢失记录
- 自动审批完成后通过增量文件同步更新状态，避免重复重建完整 Codex 会话

## 说明
- 完整有效会话历史继续保留；优化只跳过原本不会被 Ping Island 使用的 rollout 记录
- 应用版本为 `0.28.2 (71)`；fork 使用 `v0.28.2-x` Release 标识

## Improvements
- Parses Codex rollouts incrementally with a file cursor and accumulated state, processing only appended JSONL data
- Skips rollout records that do not contribute to session state or displayed history before JSON decoding during cold starts
- Merges session snapshots and concurrent approval queues in linear time, avoiding quadratic CPU usage on long histories
- File refreshes no longer request complete App Server turns first, and session details prefer the local cache

## Fixes
- Preserves partially written trailing JSONL records until the next append instead of losing them under concurrent writes
- Refreshes state through incremental file sync after automatic approval completes instead of rebuilding the full Codex thread

## Notes
- Complete relevant session history remains available; the optimization only skips rollout records Ping Island did not consume
- The app version is `0.28.2 (71)`; the fork uses the `v0.28.2-x` Release identifier
