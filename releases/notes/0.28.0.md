## 新功能
- 新增模型辅助智能审批，可连接 OpenAI 兼容接口判断响应式 Hook 的允许或拒绝
- 支持独立多选低、中、高风险等级进行人工确认；未选中的等级按模型结论自动处理
- 支持选择是否显示轻量的 AI 审批中提示，模型处理期间不会弹出人工审批操作
- 新增关联会话和工具调用的 30 天本地审计，界面简要展示并可导出完整上下文 JSON

## 修复
- 修复同一会话大量并发 Hook 审批时请求丢失、相互覆盖或只能确认一次的问题
- 修复 Codex rollout 和 thread-list 刷新覆盖本地待审批队列的问题
- 修复人工确认与模型返回竞态导致重复回调或审批弹窗再次出现的问题
- 修复悬浮审批提示背景高度过大，以及评估提示无法按设置自动展示的问题

## 说明
- 智能审批只处理可回写的单次 Hook 请求，不会自动授予整个会话权限
- API Key 保存在本机钥匙串，不进入日志、诊断、遥测或审计记录
- Sparkle build 号提升到 `69`，版本号提升到 `0.28.0`

## New
- Adds model-assisted approval for responsive hooks through an OpenAI-compatible endpoint
- Adds independent low, medium, and high-risk selections for mandatory manual confirmation
- Adds an optional lightweight evaluating hint while keeping model processing out of manual approval UI
- Adds a 30-day session-linked local audit with compact in-app rows and full-context JSON export

## Fixes
- Fixes dropped, superseded, or single-shot behavior when many hook approvals arrive concurrently in one session
- Preserves locally pending Codex hook approvals across rollout and thread-list refreshes
- Prevents manual-response and model-response races from sending duplicate callbacks or reopening prompts
- Tightens detached approval hint sizing and restores automatic presentation according to the hint setting

## Notes
- Model-assisted approval only resolves one responsive hook request at a time and never grants session-wide access
- API keys remain in the local Keychain and are excluded from logs, diagnostics, telemetry, and audit records
- The Sparkle build number is now `69`, and the app version is now `0.28.0`
