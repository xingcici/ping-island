## 新功能
- 智能审批模型上下文改为分层组装，优先使用会话摘要、最新用户指令、最近对话窗口和当前工具输入
- 模型请求上下文限制为 64 KiB；超长工具输入保留关键字段、首尾预览、原始大小和 SHA-256，减少上下文过大导致的失败

## 改进
- 上下文预算计算移出审批客户端的串行执行区，避免并发 Hook 请求在模型调用前相互阻塞
- AIApproval 生命周期日志记录上下文大小、截断状态和省略数量，同时不记录敏感正文
- 完整审计导出继续保留未经截断的会话摘要、对话和工具输入

## 说明
- 智能审批只处理可回写的单次 Hook 请求，不会自动授予整个会话权限
- API Key 保存在本机钥匙串，不进入日志、诊断、遥测或审计记录
- 应用版本为 `0.28.1 (70)`；`xingcici/ping-island` fork 使用 `v0.28.1-x` Release 标识

## New
- Builds model context in layers, prioritizing the session summary, latest user instruction, recent conversation window, and current tool input
- Caps model request context at 64 KiB; oversized tool input retains priority fields, head/tail previews, original size, and SHA-256 metadata

## Improvements
- Prepares context outside the approval client's serialized execution path so concurrent hook requests do not block one another before model calls
- Logs context size, truncation state, and omitted counts in the AIApproval lifecycle without logging sensitive content
- Keeps the full untruncated session summary, conversation, and tool input in audit exports

## Notes
- Model-assisted approval only resolves one responsive hook request at a time and never grants session-wide access
- API keys remain in the local Keychain and are excluded from logs, diagnostics, telemetry, and audit records
- The app version is `0.28.1 (70)`; the `xingcici/ping-island` fork uses the `v0.28.1-x` Release identifier
