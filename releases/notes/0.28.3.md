## Improvements
- Persists model-assisted approval audits incrementally in local SQLite instead of rewriting the complete history for every decision
- Moves audit writes to a serial background queue, reducing local delay between model completion and the automatic Hook response
- Migrates the legacy JSON audit automatically while preserving full JSON export and the 30-day/1,000-record retention policy

## Notes
- Audit records continue to retain complete session, tool-input, and context data without API keys
- The app version is `0.28.3 (72)`; the `xingcici/ping-island` fork uses the `v0.28.3-x` Release identifier
