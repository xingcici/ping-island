## 改进
- 智能审批审计改用本地 SQLite 增量持久化，避免每次审批重写完整历史文件
- 审计写入移至后台串行队列，减少模型完成后到 Hook 自动回调之间的本地等待
- 旧版 JSON 审计会自动迁移，完整 JSON 导出和 30 天/1,000 条保留策略不变
- Codex rollout 采用游标和累积状态增量解析，文件追加时只处理新增 JSONL 数据
- 冷启动会在 JSON 解码前跳过无关记录，会话快照和并发审批队列改为线性合并
- 文件刷新不再请求完整 App Server turns，自动审批完成后改用增量文件同步

## 修复
- 正确保留分段写入的最后一条 JSONL，避免并发追加时丢失记录

## 说明
- 审计记录继续完整保留会话、工具参数和上下文，不包含 API Key
- 应用版本为 `0.28.3 (72)`；`xingcici/ping-island` fork 使用 `v0.28.3-x` Release 标识

## Improvements
- Persists model-assisted approval audits incrementally in local SQLite instead of rewriting the complete history for every decision
- Moves audit writes to a serial background queue, reducing local delay between model completion and the automatic Hook response
- Migrates the legacy JSON audit automatically while preserving full JSON export and the 30-day/1,000-record retention policy
- Parses Codex rollouts incrementally, skips irrelevant cold-start records, and merges session snapshots in linear time
- Avoids complete App Server turn reads during file refreshes and uses incremental file sync after automatic approval

## Fixes
- Preserves partially written trailing JSONL records until the next append instead of losing them under concurrent writes

## Notes
- Audit records continue to retain complete session, tool-input, and context data without API keys
- The app version is `0.28.3 (72)`; the `xingcici/ping-island` fork uses the `v0.28.3-x` Release identifier
